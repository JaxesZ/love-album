# 照片文件夹 📷

把你想展示在相册里的照片**直接拷贝到这个文件夹**，然后在 `manifest.json` 里列出文件名即可。

## 操作步骤

### 1. 把照片放进来

直接把图片文件拖到 `images/` 文件夹下，比如：

```
images/
  ├── manifest.json
  ├── 第一次见面.jpg
  ├── 旅行.jpg
  ├── 日常.png
  └── ...
```

> **建议**：文件名用英文或拼音，避免空格和特殊符号，部署后更稳。中文也能用，但有些服务器/浏览器会出现 URL 编码问题。

### 2. 编辑 `manifest.json`

打开 `manifest.json`，在 `photos` 数组里列出照片文件名（**顺序就是展示顺序**）：

```json
{
  "photos": [
    "第一次见面.jpg",
    "旅行.jpg",
    "日常.png"
  ]
}
```

### 3. 刷新网页

刷新浏览器就能看到你放进去的照片了。

> 如果是已经部署到 GitHub Pages 的版本，要 `git add . && git commit -m "更新照片" && git push`，然后等 1-2 分钟才会生效。

## 注意事项

- **图片尺寸建议**：单张照片控制在 **1-2 MB** 以内，太大会拖慢加载速度。可以用网上的图片压缩工具（如 TinyPNG）压一下。
- **图片数量建议**：10-30 张体验最好，太多会让首屏加载变慢。
- **如果 `manifest.json` 不存在或为空**，相册会自动回退到使用 Unsplash 的远程示例照片，**不会报错**。
- **本地新增照片对"已上传"的用户上传照片没有影响**——你自己上传的照片仍然保留在浏览器 LocalStorage 里。

## 支持的格式

`jpg` / `jpeg` / `png` / `webp` / `gif`
